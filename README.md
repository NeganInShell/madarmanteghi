# 🧠 Madar Manteghi (مدار منطقی)

## 📌 معرفی پروژه
این مخزن شامل پیاده‌سازی و شبیه‌سازی مدارهای منطقی دیجیتال با تمرکز بر **Encoder** و **Decoder** می‌باشد.  
پروژه با هدف درک عمیق منطق دیجیتال، شبیه‌سازی رفتار واقعی مدار و استقلال از ابزارهای گرافیکی آنلاین توسعه داده شده است.

## ⚙️ ابزارها و تکنولوژی‌ها
- **Verilog HDL** – طراحی مدار دیجیتال
- **Icarus Verilog (iverilog)** – شبیه‌سازی
- **GTKWave** – مشاهده Waveform
- **Python + Tkinter** – شبیه‌ساز گرافیکی آفلاین
- **Git & GitHub** – کنترل نسخه

---

## 🧩 اجزای پروژه
- ✅ Priority Encoder 4-to-2  
- ✅ Error Detection (تشخیص فعال بودن چند ورودی)
- ✅ Decoder 2-to-4 متصل به خروجی Encoder
- ✅ Truth Table زنده
- ✅ شبیه‌ساز گرافیکی با نمایش:
  - سوئیچ‌ها
  - گیت‌ها
  - سیم‌های فعال
  - LED خروجی

---

## 📂 ساختار فایل‌ها

.
├── encoder.v           # Encoder (Verilog)
├── tb_encoder.v        # Testbench
├── encoder.vvp         # فایل اجرایی شبیه‌سازی
├── encoder.vcd         # خروجی Waveform
├── encoder.py          # شبیه‌ساز منطقی ساده
├── encoder_gui.py      # شبیه‌ساز گرافیکی (Tkinter)
└── README.md

---```

## ▶️ نحوه اجرا (Verilog)
bash
iverilog encoder.v tb_encoder.v -o encoder.vvp
vvp encoder.vvp
gtkwave encoder.vcd

---

## ▶️ اجرای شبیه‌ساز گرافیکی
bash
python encoder_gui.py

بدون نیاز به نصب کتابخانه اضافی ✅
